# Bank-Loan-Analysis
Bank Loan Analysis Dashboard Using Python, Excel and Power BI
Bank Loan Risk & Performance Analysis Dashboard

## Project Overview

This project focuses on analyzing bank loan data to identify loan performance, customer risk patterns, repayment behavior, and funding trends using data analytics and business intelligence tools.

The project was developed as an end-to-end analytics solution using SQL, Python, Excel, Power BI, and Tableau to transform raw loan data into meaningful business insights and interactive dashboards.

## Dataset
Source: Publicly available bank loan dataset used for analytical purposes.

## Business Objective

- The main objective of this project is to:
- Analyze loan applications and repayment trends
- Identify good loans and bad loans
- Monitor loan recovery performance
- Track monthly loan growth
- Understand customer borrowing behavior
- Build interactive dashboards for decision-making

## Key Business Insights
- Total Loan Applications reached approximately 39K
- Total Funded Amount exceeded $435M
- Total Amount Received crossed $473M
- Good Loans accounted for approximately 86.2%
- Bad Loans accounted for approximately 13.8%
- Debt Consolidation was the most common loan purpose
- 36-month term loans were higher than 60-month loans
- Customers with longer employment length showed higher funded amounts
